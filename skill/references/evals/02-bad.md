The error that you're encountering, which is `ECONNREFUSED 127.0.0.1:5432`, is essentially indicating that the PostgreSQL server isn't accepting connections on the default port, which is most likely due to the fact that postgresql@16 wasn't started after your reboot, as opposed to this being a bug in the application code, which it is not. Your .env file has DATABASE_URL pointing at localhost:5432, so the app is looking in the right place, and the former is fine while the latter is the problem. The server can be started with `brew services start postgresql@16`, after which it can be confirmed that it's running by using `pg_isready`, which should print "accepting connections". If it still fails after that, the log at /opt/homebrew/var/log/postgresql@16.log should be checked, and it's also not impossible that a second Postgres is not releasing the port, in which case you'd want to see what is holding 5432 with `lsof -i :5432`.
